# Project-Clot 가격 동향 인터랙티브 시각화 대시보드 (`visualize`) 기획 및 UI/UX 상세 사양서

> **문서 상태:** 그릴링 완료 및 의사결정 확정 (Fully Converged)  
> **최종 갱신일:** 2026-09-03  
> **대상 시스템:** `project-clot` (무신사 가격 추적 및 위시리스트 관리 시스템)

---

## 1. 프로젝트 개요 및 목표

### 1.1 배경
`project-clot`은 무신사의 관심 상품을 매일 백그라운드(`launchd`)로 수집하여 정상가, 판매가, 그리고 회원 등급 및 쿠폰이 적용된 **'나의 최종 실구매가'**를 시계열로 SQLite(`data/prices.db`)에 누적하고 있습니다. 현재 터미널 CLI(`clot list`, `clot history`)로만 확인 가능한 가격 데이터를, 누구나 한눈에 탐색하고 분석할 수 있는 **무신사 스타일의 인터랙티브 웹 대시보드**로 시각화합니다.

### 1.2 핵심 목표
1. **무신사 룩앤필 상품 그리드:** 무신사 스토어와 유사한 고밀도 상품 카드 그리드로 85개 이상의 추적 상품을 직관적으로 브라우징.
2. **원클릭 차트 모달:** 상품 카드를 클릭하면 정가, 판매가, 실구매가 3중 시계열 라인과 역대 최저가 핀 마커가 포함된 인터랙티브 차트 모달 팝업.
3. **독립형 단일 파일(Standalone HTML):** 별도의 웹 서버 구동 없이 `data/dashboard.html` 단일 정적 파일로 생성되어 macOS `open` 명령어로 즉시 브라우저 실행.
4. **완전 자동화:** 매일 아침 데몬 실행(`daily`) 완료 시 대시보드가 자동 갱신되며, 에이전트 슬래시 커맨드(`/visualize`)로 언제든 원클릭 호출 가능.

### 4.1 핵심 모듈 역할
1. **`src/visualizer.js`**:
   - `prices.db`에서 상품 메타데이터 및 날짜별 시계열 가격 이력 조회.
   - 통계 지표(총 상품 수, 어제 대비 하락 상품 수, 역대 최저가 갱신 상품 수 등) 사전 계산.
   - 단일 HTML 파일에 Tailwind CSS, Chart.js CDN과 함께 `window.__CLOT_DATA__`를 인라인 주입하여 저장.
2. **`src/cli.js`**:
   - `clot visualize [goodsNo] [--no-open]` 서브커맨드 처리.
   - `handleDailyRun()` 종료 직전 `generateDashboardHtml()` 자동 호출.
3. **`.agents/skills/visualize/SKILL.md`**:
   - 에이전트에게 `/visualize` 호출 규칙 및 실행 후 최저가 갱신 현황 요약 브리핑 가이드 제공.

## 5. 실행 워크플로우

1. **수동 열람**:
   ```bash
   npm run visualize
   # 또는
   node src/cli.js visualize
   ```
   -> `data/dashboard.html`이 즉시 최신 데이터로 빌드되고 macOS 기본 브라우저 새 탭으로 자동 오픈.

2. **특정 상품 딥링크 열람**:
   ```bash
   node src/cli.js visualize 6084885
   ```
   -> 대시보드가 열리며 해당 상품의 가격 동향 차트 모달이 자동으로 팝업.

3. **에이전트 호출**:
   - 사용자가 채팅에서 `/visualize` 입력 시 에이전트가 위 명령어를 백그라운드로 실행하고 브라우저를 띄운 뒤, 오늘 최저가를 갱신한 주요 상품 2~3개를 채팅창에 요약 보고.

4. **자동 데일리 갱신**:
   - 매일 오전 09:30 `launchd` 데몬이 `clot daily`를 실행할 때 데이터 수집 후 `dashboard.html`도 자동 업데이트되므로 언제 열어도 최신 상태 유지.

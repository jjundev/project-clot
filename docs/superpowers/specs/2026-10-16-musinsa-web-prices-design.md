# 무신사 대량 수집 가격 웹 연결

사용자가 요청한 30만 상품 연결, 직접 확인/추정 가격 구분, 쿠폰 예외 경고, 실제 배포 확인을 구현한다. 기존 대시보드 외형·검색·출처/브랜드 필터·4910을 유지한다.

무신사 Release DB를 읽기 전용으로 빌드에 연결한다. ACTIVE 상품(당일 선택 300,000과 이전 회차 잔류 상품 포함)을 전부 분할 요약으로 제공하고 이력은 별도 분할 파일로 필요할 때 읽는다. 중복 무신사 상품은 wide DB를 우선하며 기존 찜 DB를 수정하지 않는다. 최신 가격 및 이력의 DIRECT / ESTIMATED / 불명 출처를 유지하고 서로 다른 출처의 가격을 확정 하락·최저가로 혼동하지 않는다. 카드와 상세에 가격 종류 및 관측일을 표시한다. 추정 가격 이력/차트는 실구매가라고 부르지 않는다.

전체 데이터 집계가 끝나기 전에 무신사 일부 수를 전체 수로 표시하지 않는다. 현재 revision 검증·실패 재시도·2,000개 단위 요약·최대 4개 동시 요청 구조를 재사용한다. 원본 DB/가격 검증 실패는 배포를 실패시켜 기존 정상 사이트를 유지한다. 회원 쿠키/원시 회원 응답은 정적 파일에 내보내지 않는다.

빌드 메타데이터에 수집일·고유 선택 수·ACTIVE 수·직접/추정 수·쿠폰 예외 번호를 넣는다. 예외가 있으면 사용자가 읽을 수 있는 경고로 실제 결제 가격이 더 낮을 수 있음을 알린다. 매일 Musinsa wide scan 성공 뒤 Pages가 갱신되도록 연결한다. 실제 Release DB로 빌드·산출물 전수 검증·브라우저 데스크톱/모바일을 점검하고 배포 URL을 직접 검증해 결과 Markdown에 기록한다.

# 첫 상품 즉시 표시와 범위별 검색 로딩

2026-10-17 KST. 사용자는 grill-yourself 설계 B안과 미확인 필터 건수 `—` 표시를 승인하고 구현을 요청했다. 이 문서는 해당 설계를 구현 계획과 함께 보존한다.

## 목적

접속하면 상품을 즉시 표시하고 현재 출처·카테고리에 필요한 검색 인덱스만 받는다. 전체 인덱스 완료는 첫 상품 표시의 선행 조건이 아니다. 전체 범위의 정확한 검색은 전체 인덱스를 요구할 수 있다. 절대 로딩 시간은 보장하지 않고 측정한다.

## 동작

- 전체·무신사·4910 각각 기본 정렬 첫 120개 이하를 미리 준비한다. HTML에서는 상품 키로 중복을 제거한다.
- 저장 필터가 기본 조건과 다르면 해당 출처의 기본 상품을 보여주되 `검색 준비 중 · 기본 상품 미리보기`라고 표시한다. 이를 선택 조건의 검색 결과나 0건으로 가장하지 않는다.
- 인덱스는 출처 × 카테고리로 분리한다. 선택 범위 로딩 완료 후 검색·정렬·페이지 결과와 결과 건수를 확정한다.
- 범위 밖 필터 건수를 계산하려고 추가 다운로드하지 않는다. 아직 계산할 수 없는 건수는 `—`로 표시한다. 데이터가 모두 있는 경우 기존 모델의 정확한 건수와 일치한다.
- 전체·각 출처의 기본 조건 집계는 빌드 시 계산해 미리 제공한다. 검색어·가격·브랜드 조건이 다른 경우 그 집계를 재사용하지 않는다.
- 이미 받은 인덱스를 재사용하고 진행 중 요청을 합친다. 다운로드 동시 실행은 최대 4개다. 검색 조건 변경 시 이전 대기 작업보다 최신 범위를 우선하며 오래된 결과를 적용하지 않는다.
- 실패 시 기존 상품과 조건을 유지하고 오류·재시도를 제공한다. 모든 파일 요청은 15초 시간 제한을 둔다.
- 상품 키로 카드 파일을 찾는 분할 경로 인덱스를 제공하여 직접 링크가 전체 검색 다운로드를 유발하지 않게 한다. 미존재 상품은 명확히 안내한다.

## 유지할 기능과 범위

GitHub Pages 정적 호스팅, HTTP Worker와 file:// 대체 경로, 기존 부분 문자열 검색·정렬·페이지·브랜드 다중 선택·직접 링크·상세 이전/다음, 가격 출처·기준일·쿠폰 예외 안내를 유지한다. 상세의 최근 90일 기본 조회, 원문 이력 캐시 16MiB 상한, 자산 파일 256KiB 이하를 유지한다. 수집 DB·과거 이력·가격 계산 정책은 변경하지 않는다. 검색 서버, 유료 서비스, 전면 UI 재설계는 제외한다.

## 수용 기준

인덱스 요청을 중단해도 첫 상품이 보인다. 무신사·상의 검색은 다른 출처·카테고리 인덱스를 요청하지 않는다. 정확한 결과·순서·페이지는 기존 모델과 동등하다. 미확인 건수는 `—`다. 지연·실패·재시도·범위 전환·미존재 상품·직접 링크를 HTTP와 file://에서 확인한다. 같은 데이터로 첫 카드 시간, 선택 범위 검색 준비 시간, 실제 요청 파일 수와 압축 전송량을 측정한다.

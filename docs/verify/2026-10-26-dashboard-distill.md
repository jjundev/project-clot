# 가격 대시보드 UI 단순화 — 2026-10-26

브랜치 `codex/musinsa-dashboard`, 이전 구현 `d7bccdb`의 후속 변경이다. 사용자의 `진행해`에 따라 카드의 할인율·정상가는 상세로 옮기고, 차트는 혜택 적용 가격 한 줄을 기본으로 하는 추천안을 적용했다.

## 변경과 대가

- 헤더 영문 부제·새로고침 버튼, 중복 목록 제목·설명, 필터별 상품 수와 현재 렌더링 수, 브랜드 선택 안내를 제거했다.
- 결과 수·필터 버튼·정렬을 한 줄로 모았다. 세부 필터는 기본 접힘이며 `aria-expanded`/`aria-controls`로 상태를 알린다. 접어도 선택은 유지되고 적용 조건은 요약한다.
- 초기화는 출처·카테고리·브랜드·가격/판매 상태·과거 기록 포함을 해제하며, 입력 중인 검색어와 정렬은 유지한다.
- 카드에는 이미지·브랜드·상품명·현재가·하락액과 해당 상태만 남겼다. 혼합 출처의 4910 표시, 추정가/출처 미확인, 갱신 지연/마지막 확인 시각, 품절/재검증 필요는 유지한다.
- 상품번호·마지막 확인 시각·판매가·쿠폰·검증일·적립금 예상가와 가정·무신사 추정가 설명은 상세의 `가격 기준`에 모았다.
- 차트의 기본 축 범위는 표시 중인 가격으로 계산한다. `다른 가격 비교`를 켜면 정상가·판매가·해당하는 신규회원가를 포함하며, 현재 가격과 URL은 변하지 않는다.
- 가격 기록 표는 접혀 있다. 차트/이력 로딩 실패 시 자동으로 펼쳐 재시도와 기록을 제공한다. 자동으로 열린 표는 복구 후 접고, 사용자가 직접 연 표는 유지한다.
- 따뜻한 흰색 배경과 옅은 구분선을 사용했다. 가격 계산·수집·Worker/분할 asset·검색·이력 API 계약은 변경하지 않았다.

세부 필터, 가격 근거, 기록 표와 비교 가격을 보려면 각각 한 번 더 조작해야 한다. 오류·재시도·빈 결과와 가격의 예외 상태는 필요한 상황에 표시한다.

## 가격 표시와 쿠폰 예외

카드·상세·이력에서 직접 확인 가격과 추정가, 기준일을 표시한다. 추정가에 확정 하락/최저가 표식을 붙이지 않으며 차트 툴팁도 가격 출처를 안내한다. 출처가 바뀐 이력을 확정 가격 하락으로 비교하지 않는다. 과거 change-only 이력은 해당 날짜의 성공한 가격 계산 증거를 확인해 DIRECT 출처를 이어간다.

목록 API 예외 쿠폰 8종: `352657, 353460, 354094, 354317, 354389, 355026, 355780, 359631`.

화면에 예외 번호와 함께 **추정가는 확인된 혜택 기준이며 실제 결제 가격이 더 낮을 수 있음**을 알린다. 이 예외가 해결되었다거나 30만 상품 전수 회원가를 직접 확인했다고 주장하지 않는다. DIRECT는 수집 당시 해당 가격 기준에서 저장된 회원 조회/쿠폰 계산 근거이며 새 결제 화면 전수 조회가 아니다.

## 자동 갱신과 운영 한계

Pages가 `data-musinsa` Release DB를 필수로 읽고 일일 커버리지/가격 출처 검사에 실패하면 새 배포를 중단한다. `Musinsa wide scan` 성공 후 자동 재배포하도록 연결했다. 이 연결 설정과 이번 실제 배포는 확인했으며 다음 날 스케줄 실행은 아직 관측하지 않았다.

이는 이미 완료된 2026-10-16 조사·가격 계산의 웹 반영이다. 이번 작업에서 새로운 30만 상품 조사나 회원 조회를 추가 수행하지 않았다. 모든 추정 가격의 실제 회원 결제 가격 정확도를 증명하는 결과는 아니다.

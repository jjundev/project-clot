## 가격 정확도 정책

- `DIRECT`: 오늘 회원 직접 조회 기록이 있고, 현재 스냅샷의 판매가·추가 할인이 그때와 같은 상품. 오늘 유효한 직접 반환 쿠폰만으로 계산한다. 목록 추정이 직접 결과를 덮어쓰지 않는다.
- `ESTIMATED`: 정상 목록 매핑과 유효한 기존 직접 조회 캐시를 이용한 확인된 혜택 기준 추정 가격. 현재 계정의 실제 결제가 보증이 아니며 추가 쿠폰·적용 조건 변화로 차이가 날 수 있다. 기존 직접 캐시는10일 이내의 추정 보완에만 사용하고 오늘 확인 가격으로 승격하지 않는다.
- DB의 `goods.coupon_price_source`와 이력의 `coupon_price_changes.source`에 출처를 저장한다. 과거 출처가 없는 행은NULL 그대로 보존했다.
- 쿠폰가의 확정 하락 알림은 **이전과 현재 이력 모두DIRECT일 때만** 생성한다. 추정 가격이나 과거 출처 미상 가격으로 확정 하락 알림을 만들지 않는다. 공개 판매가 알림은 ‘판매가’로 별도 구분한다.
- 복구 실행 자체는 가격 하락 알림을 보내지 않았다. 일상 보고서에는 추정/직접 확인 수, API 예외ID, 추가 할인 가능성 경고를 표시한다.

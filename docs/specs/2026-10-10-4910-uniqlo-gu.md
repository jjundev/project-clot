# 4910(에이블리 남성관) 유니클로·GU 가격 추적 — 설계

Source: 2026-10-10 grill-yourself session. Needs-you rows #1, #11, #12 were not answered → **[confirmed by default]** with the assumed values below.

## Intent
GitHub Actions의 daily 실행에 4910.kr 수집 단계를 붙여, 4910에 올라온 **유니클로(brand 2421)·GU(brand 13647) 브랜드의 모든 판매글**을 매일 1회 스캔하고 가격 변동·신규·종료를 기록한다. 완료 기준: 스케줄 실행 한 번에 무신사 + 4910이 함께 수집되고, 4910 데이터가 `data/4910.db`로 커밋되며, 텔레그램으로 4910 일일 요약 1통이 오고, 4910이 실패해도 무신사 수집·커밋은 영향받지 않는다.

Classification: architectural — 새 외부 소스(에이블리 aglo API), 새 저장소, 기존 대비 ~25배 규모.

Fact: 4910의 "유니클로" 상품은 공식몰이 아니라 일본 구매대행 셀러(LUXURYJP, 일본쵸루상, 모에모에 등 20여 곳)의 판매글이다(`is_official_brand: false`). 2026-10-10 기준 유니클로 10,529 + GU 5,359 ≈ 15.9k. 추적 단위는 판매글(`sno`).

## Behavior when done
- `node src/cli.js daily`가 무신사 수집 뒤 4910 스캔(≈50 요청, 1분 내)을 수행하고 로그에 브랜드별 스캔 수와 신규/가격변동/종료 수를 남긴다.
- 단독 실행: `node src/cli.js track-4910 [--brand uniqlo|gu] [--dry-run]`. `--skip-4910`으로 daily에서 제외.
- 텔레그램 1통/일: 브랜드별 스캔 수, 신규·가격변동·종료·재등장 수, 직전 기록가 대비 **10% 이상 하락** 상위 10개.
- 4910 실패 시 `⚠️ [4910] 수집 실패 (사유)`만 남기고 무신사 커밋·Pages 배포는 정상 진행.
- probe 모드에서 러너→4910 도달성(익명 토큰 → 목록 1페이지)을 확인.

## API facts (verified 2026-10-10)
- Token: `GET https://api.a-bly.com/api/v2/anonymous/token/` → `{ "token": "<143 chars>" }`. 토큰 없이 목록 API는 401.
- List: `GET https://api.a-bly.com/aglo/api/brands/{sno}/goods/?brand={sno}&member_gender=ALL&sorting_type=NEW&limit=500[&min_price=][&max_price=][&last_sno=]`, headers `X-Anonymous-Token`, `Origin: https://4910.kr`, `Referer: https://4910.kr/`.
  - Response `{ total_count, goods_list[], last_sno, has_other_gender_goods }`; `last_sno: null` = 끝. `limit` 상한 500.
  - 한 쿼리의 커서 페이지네이션은 **약 3,000개에서 끊긴다**(NEW 3,005, RECOMMEND 500). 가격 구간 필터(`min_price`/`max_price`, 양끝 포함)로 나누면 구간 전체가 순회된다(50,000–59,999 → 1,703/1,703).
  - Entry: `item.{sno,name,market_sno}`, `logging.analytics.{MARKET_NAME,STANDARD_CATEGORY_NAME,SALES_PRICE,DISCOUNT_RATE,BRAND_SNO}`, `render.data.{original_price("51,300"|null), closed_reason, image.url}`.
- 상품 URL: `https://4910.kr/goods/{sno}` (→ `/desktop/goods/{sno}`).
